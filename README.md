## Featured projects

### [TCGVault](https://tcgvault.app.br)
SaaS in closed beta for managing Pokémon card collections, built solo with an AI-first workflow using Codex and Claude. It tracks prices, sends target-price alerts and compares Brazilian and international prices. It integrates 3 APIs into a base of 23,000 cards, with a matching algorithm across catalogs that never approves a match on name alone.

`React` `Vite` `Supabase` `Node.js` `Vercel` · The source code is private. The photo identification feature has its [own public repository](https://github.com/Jpcerq/tcg-card-identifier).

### Ponte
Peer-to-peer file transfer PWA over WebRTC, with no server-side storage. It has its own WebSocket signaling server, plus STUN and Cloudflare TURN.

`Node.js` `WebRTC` `WebSocket` `Docker`

### [Exploration robot (IoT)](https://github.com/Jpcerq/robo-explorador-iot)
ESP32-S3 robot controlled over MQTT, with sensor telemetry stored through a Flask and SQLite API. Team project.

`ESP32` `MQTT` `Flask` `SQLite`

### [Lock Screen Composer](https://github.com/Jpcerq/windows-lock-screen-composer)
Windows tool that composes multiple images and GIF frames into a custom lock screen, with control over position, size, stacking and rounded corners.

`PowerShell`

## 🔨 What I'm building now

Photo-based card identification for TCGVault, using image embeddings. Still in development, in [tcg-card-identifier](https://github.com/Jpcerq/tcg-card-identifier).
